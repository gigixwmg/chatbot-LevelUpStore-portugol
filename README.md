# Chatbot LevelUp Store

Projeto de lógica de programação em Portugol (VisualG) que simula o atendimento ao cliente da empresa fictícia LevelUp Store.

## Funcionalidades

- Consulta de produtos
- Informações sobre entrega
- Informações sobre pagamento
- Atendimento interativo por menus
- Repetição do atendimento até o usuário escolher sair

## Conceitos utilizados

- Variáveis
- Estruturas condicionais (SE)
- Estruturas de repetição (ENQUANTO)
- Entrada e saída de dados
- Menus interativos

## Tecnologias

- Portugol
- VisualG

## Objetivo

Praticar conceitos fundamentais de lógica de programação por meio da criação de um chatbot de atendimento para uma loja geek fictícia.
